# Repository settings

GitHub repository settings are managed by the repository owner in GitHub. Files
in this repository do not apply branch protection, change Pages settings, create
environments, or set approval counts.

The current [CODEOWNERS](../.github/CODEOWNERS) rule keeps `@sid0709` as the
repository owner for all paths. Keep that owner in place when discussing any
future ownership changes. Do not assume this document describes settings that
have already been enabled; the owner can review and configure them in the GitHub
UI.
