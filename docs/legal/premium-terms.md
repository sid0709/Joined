# Draft — not legal advice

## What Premium is

Joined Premium is an optional subscription for extra job-search features. The free plan remains available. These draft terms do not set a price. The pricing page shows the amount configured for the environment.

## Test mode

Checkout uses Stripe test mode. `STRIPE_ALLOW_LIVE` defaults to false, so this draft does not collect live charges and it does not describe a production card charge. A live charge requires that switch to be turned on outside this repository, with written approval, before any customer is billed.

## Billing period

Monthly and yearly plans renew until you cancel. You can open the billing portal from settings to manage or cancel a test subscription. Canceling stops the next renewal. Access for the current period follows the status Stripe returns.

## Refunds

This draft does not promise a refund. Support and admin tools can record a refund decision. A refund in test mode does not move live money.
