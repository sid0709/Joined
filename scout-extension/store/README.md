# Chrome Web Store materials

Copy for an **unlisted** Scout upload. `listing.md` records `Distribution: unlisted` because a public listing has not been chosen. The zip comes from `bun --filter scout-extension package`. Nothing in this folder is uploaded as a file except the icon you copy from `public/` if the dashboard asks for one. Do not upload from CI.

| File                           | Dashboard field                                |
| ------------------------------ | ---------------------------------------------- |
| `listing.md`                   | Name, summary, description, category, language |
| `single-purpose.md`            | Single purpose                                 |
| `permission-justifications.md` | Permission justifications                      |
| `privacy-practices.md`         | Privacy practices questionnaire                |
| `assets.md`                    | Icon and screenshot sizes (specs only)         |
