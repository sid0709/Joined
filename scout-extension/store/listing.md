## Description

Scout is the browser companion for Scoutwell, Joined's scout product.

Scouts grow a pool of official, hard-to-find jobs. The extension opens a side panel where you sign in to your Scoutwell account and see that you are signed in. Later releases use the same panel to capture a listing from the page you already have open. Nothing here adds new Chrome permissions.

Use Scout to:

- Open the side panel from the toolbar
- Sign in through Scoutwell in a new tab
- See your scout name, email, and level when the session is valid

Scout talks only to Scoutwell: the Scout website for sign-in and the Scout API for your profile. It does not inject a content script on every site, run remote code, or sell data.

Install is unlisted. Share the store link with scouts who should load this build. For local development, load `scout-extension/dist` unpacked instead of this zip.
